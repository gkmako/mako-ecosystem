# Сборщик новостей по электромобилям в РФ

Этот проект собирает новости по теме электромобилей в России из различных источников, включая RSS-ленты и веб-сайты.

## Функционал

- Сбор новостей через RSS (Autonews, Motor.ru, За рулем, Колеса.ру, Google News)
- Парсинг новостных сайтов (РБК Авто, Коммерсантъ Авто)
- Фильтрация по ключевым словам
- Дедупликация новостей
- Сохранение в SQLite
- Экспорт в CSV
- Периодический запуск
- Логирование и обработка ошибок

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <repo-url>
   cd ev_news_collector
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Конфигурация

Все настройки находятся в файле `config.py`:
- RSS-источники
- URL Google News
- Список веб-сайтов для скрапинга
- Ключевые слова для фильтрации
- Пути к БД и CSV-файлу

## Использование

Для запуска сборщика выполните:
```bash
python main.py
```

При первом запуске будет выполнен сбор новостей, затем запустится планировщик, который будет собирать новости каждые 2 часа.
