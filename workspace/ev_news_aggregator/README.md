# Автоматизированный сборщик новостей по тематике электромобилей в РФ

## Описание

Этот проект представляет собой автоматизированный сборщик новостей по тематике электромобилей в Российской Федерации. Скрипт собирает данные из различных RSS-лент, Google News и веб-сайтов, фильтрует их по ключевым словам и сохраняет в различных форматах.

## Особенности

- Сбор новостей из RSS-лент популярных автопорталов
- Парсинг Google News по ключевым запросам
- Фильтрация по ключевым словам
- Удаление дубликатов
- Сохранение в SQLite, CSV и JSON
- Экспорт истории новостей
- Уведомления в Telegram (опционально)
- Логирование всех операций

- За рулем (https://www.zr.ru/rss/)

## Требования

- Python 3.8+
- Зависимости из requirements.txt

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <repo-url>
   cd ev_news_aggregator
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Конфигурация

Все настройки находятся в файле `src/config.py`. Вы можете изменить:
- Список источников новостей
- Ключевые слова для фильтрации
- Пути к файлам сохранения
- Настройки HTTP-запросов
- Интервал планировщика
- Настройки Telegram (опционально)

Для настройки Telegram нотификаций создайте файл `.env` в корневой директории:
```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
```

## Запуск

### Однократный запуск:
```bash
python -m src.main
```

### Однократный запуск с отправкой в Telegram:
```bash
python -m src.main --telegram
```

### Запуск с планировщиком (по расписанию):
```bash
python -m src.main --schedule
```

### Запуск с планировщиком и отправкой в Telegram:
```bash
python -m src.main --schedule --telegram
```

## Планирование (cron)

Для автоматического запуска каждые 24 часа добавьте в crontab:

```bash
0 9 * * * /usr/bin/python3 /path/to/ev_news_aggregator/src/main.py --telegram
```

## Структура проекта

```
ev_news_aggregator/
├── src/
│   ├── __init__.py
│   ├── main.py          # Точка входа
│   ├── config.py        # Конфигурация
│   ├── scraper.py       # Логика сбора новостей
│   ├── storage.py       # Сохранение данных
│   ├── telegram_notifier.py # Отправка уведомлений в Telegram
│   └── utils.py         # Вспомогательные функции
├── data/                # Директория для сохраненных данных
├── logs/                # Логи

└── README.md            # Документация
```

## Логирование

Логи сохраняются в директорию `logs/`:
- `news_aggregator.log` - основной файл логов с ротацией
- `latest.log` - последние записи логов

## Выходные данные

Результаты работы сохраняются в директорию `data/`:
- `news.csv` - данные в формате CSV
- `news.json` - данные в формате JSON
- `news.db` - база данных SQLite

## Экспорт данных

Для экспорта истории новостей в CSV используйте функцию `export_to_csv_from_sqlite` из модуля `storage.py`.

## Разработка

Для добавления новых источников отредактируйте список `NEWS_SOURCES` в файле `src/config.py`.

Для добавления новых ключевых слов отредактируйте список `KEYWORDS` в файле `src/config.py`.
