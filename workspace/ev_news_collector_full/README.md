# Автоматизированный сборщик новостей по тематике «рынок электромобилей в РФ» (2025 год)

## Описание

Это приложение автоматически собирает новости по теме рынка электромобилей в Российской Федерации. Оно использует несколько источников информации, фильтрует статьи по ключевым словам, удаляет дубликаты и сохраняет результаты в SQLite базу данных с возможностью экспорта в CSV.

## Функциональность

- Сбор новостей по расписанию (раз в час)
- Фильтрация по ключевым словам
- Дедупликация новостей (по URL и заголовку)
- Сохранение в SQLite-базу данных
- Возможность выгрузки в CSV

## Требования

- Python 3.10+
- Зависимости из `requirements.txt`

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Конфигурация

Все настройки находятся в файле `config.py`:
- `RSS_SOURCES`: список RSS-лент
- `WEB_SOURCES`: список веб-сайтов для парсинга
- `GOOGLE_NEWS_RSS`: URL Google News RSS
- `KEYWORDS`: ключевые слова для фильтрации
- Пути к файлам БД и экспорта
- Интервал планировщика

## Запуск

Для запуска приложения выполните:
```
python main.py
```

Приложение будет работать в фоновом режиме, собирая новости каждый час.
