# Автоматизированный сборщик новостей об электромобилях РФ

Этот проект автоматически собирает, обрабатывает и систематизирует новости об электромобилях в России из различных RSS-лент.

## Функциональность

- Сбор новостей из RSS-лент
- Удаление дубликатов статей
- Хранение новостей в SQLite базе данных
- Экспорт в CSV и JSON форматы
- Генерация HTML-дайджеста новостей
- Планировщик для автоматического запуска

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repo-url>
cd ev-news-collector
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте конфигурацию в `config.yaml` при необходимости

## Использование

### Запуск единичной сборки новостей:
```bash
python main.py
```

### Автоматический запуск по расписанию:
Программа будет автоматически запускаться по расписанию, заданному в конфигурации.

## Структура проекта

- `main.py` - Главный файл приложения
- `collector.py` - Сбор новостей из RSS-лент
- `storage.py` - Хранение новостей в SQLite и экспорт в CSV/JSON
- `dedup.py` - Удаление дубликатов новостей
- `digest.py` - Генерация HTML-дайджеста
- `scheduler.py` - Планировщик задач
- `config.yaml` - Конфигурационный файл
- `requirements.txt` - Зависимости проекта
- `templates/digest.html` - Шаблон для HTML-дайджеста

## Конфигурация

Все настройки находятся в файле `config.yaml`:

- RSS-ленты для сбора новостей
- Параметры базы данных
- Настройки экспорта
- Параметры удаления дубликатов
- Настройки дайджеста
- Параметры планировщика
